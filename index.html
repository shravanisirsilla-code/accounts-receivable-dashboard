01 / OVERVIEW

Project Overview

This project demonstrates how accounts receivable data can be organised and analysed to monitor collections, identify overdue invoices and understand outstanding balances.

Objective

Monitor invoice payments, outstanding balances and receivable ageing.

Tools Used

Microsoft Excel, formulas, PivotTables, charts and data analysis.

Dataset

100 fictional invoice records created for practice and portfolio demonstration.
